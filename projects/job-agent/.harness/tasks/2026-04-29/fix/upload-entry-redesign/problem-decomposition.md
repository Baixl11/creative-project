# 问题拆解

## 用户目标

让上传 JD 和上传简历两个入口更美观、更清楚，支持格式说明不要再是一长串压缩文字。

## 当前状态

- `web_app.py` 中 `_render_upload_inputs()` 直接调用两个 `st.file_uploader()`。
- Streamlit 默认上传控件显示深色背景和长格式说明。
- 用户截图中两个上传区看起来像技术控件，而不是产品页面。

## 期望状态

- 上传区有一个简短说明头。
- JD 和简历各自有独立上传入口，说明各自用途。
- 支持格式用一行中文轻量说明展示。
- Streamlit 默认英文格式说明隐藏，避免重复和拥挤。

## 非目标

- 不自研完整上传组件。
- 不改变支持格式和文件保存逻辑。
- 不调整 Agent 分析流程。

## 首选方案

在现有 `st.file_uploader()` 外增加简洁中文标签，并通过 CSS 隐藏默认格式说明、微调上传控件视觉。

## 工作包

| 工作包 | 目标 | 文件 | 验证 |
| --- | --- | --- | --- |
| 上传入口文案 | 增加 JD/简历说明和轻量格式说明 | `web_app.py` | 单测 |
| 上传控件样式 | 覆盖 file uploader 视觉 | `web_app.py` | 编译/人工验收 |
| 测试 | 覆盖入口标签、HTML 转义和默认格式说明隐藏 | `tests/test_web_app.py` | unittest |

## 风险

- Streamlit 内部 DOM class/testid 可能随版本变化，样式可能需要后续微调。
- 最终视觉仍需要浏览器人工确认。
