# 功能测试计划

## 功能点拆分

| 功能点 | 风险 | 测试方式 | 测试数据 | 通过标准 |
| --- | --- | --- | --- | --- |
| 文本框外复制 icon | medium | 单元测试 HTML 结构 | 示例 bullet | 按钮在文本框之前且含 SVG |
| 文本转义 | high | 单元测试 | `<script>` 文本 | 输出中没有可执行脚本内容 |
| Web UI 可编译 | high | py_compile | `web_app.py` | 编译通过 |

## 核心流程测试

- 渲染建议写法 -> 生成自定义 HTML 组件 -> 用户点击外侧 icon -> 文本写入剪贴板。

## 高层验证前置条件

单元测试和编译通过后，再启动 Streamlit 做健康检查。
