## 正文

最近把一个小想法做成了可运行的桌面应用：一只会趴在桌面上的电子小宠物。

它不是壁纸，也不是普通贴图，而是一个透明悬浮在桌面上的小窗口。可以拖拽、点击、悬停互动，也能在托盘里隐藏、重置位置、打开设置或退出。

这版我先做了 5 个线稿角色：小狗、小猫、小兔、羊驼和小牛。每只都有自己的动作循环，比如发呆、跳一跳、伸懒腰、叫一声，想要做出一点“它真的住在电脑里”的感觉。

技术上用了 Electron + React + Three.js。前面先写了 PRD 定 MVP 范围，然后做透明桌面窗口、鼠标穿透、角色注册系统、中文设置面板，最后打包成 Windows 可运行的 exe。

目前还是作品集/原型阶段，下一步想继续打磨真实桌面里的动作节奏、交互手感和安装体验。

做这种小而完整的作品真的很快乐：它不一定复杂，但从“一个可爱的念头”走到“真的能跑起来”，会很有成就感。
