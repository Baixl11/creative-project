# FastAPI 安全与质量门禁

## 认证与授权

- 明确认证来源、token/cookie 生命周期、吊销、MFA 和服务间身份。
- 每个对象操作检查 tenant、Owner、角色或属性权限，防止 IDOR。
- 管理端、普通用户和内部服务使用不同权限边界；默认拒绝未知权限。
- WebSocket、后台任务和 webhook 入口也必须认证或验证签名。

## 输入与外部边界

- 文件上传检查大小、扩展名、MIME、内容、路径和解压限制。
- 远程 URL 检查协议、DNS/IP、重定向和私网目标，防止 SSRF。
- SQL 使用参数化查询；模板、命令和路径不拼接不可信输入。
- 错误响应不泄露堆栈、SQL、内部路径或认证细节。
- CORS 使用明确 origin 列表；携带凭据时禁止通配。

## 可靠性

- 外部依赖设置超时、并发限制、有限重试、抖动和失败降级。
- 只自动重试可证明幂等的操作。
- 限流策略区分用户、租户、IP、token 和高成本端点。
- 关键任务使用持久队列、去重键、重试上限和死信处理。

## 测试矩阵

| 风险 | 最小验证 |
|---|---|
| `local` | 目标单元测试、lint/typecheck 中适用项。 |
| `module` | 模块 API、数据库集成和错误路径。 |
| `contract` | OpenAPI/consumer contract、旧客户端和鉴权。 |
| `data-migration` | 迁移、backfill、回滚/前滚和混合版本。 |
| `security-critical` | 越权、输入攻击、审计、限流和秘密泄露。 |

记录命令、环境、退出码、测试数量、基线失败和新增失败。未实际运行时使用 `Not run`，环境阻塞时使用 `Blocked`。

## 运行与发布

- 配置启动时校验，缺少关键秘密立即失败。
- 日志采用结构化字段并脱敏；错误率和延迟按路由/状态/依赖分解。
- readiness 检查是否能接收流量，liveness 只检查进程健康。
- 发布前验证迁移顺序、worker 与 API 兼容、优雅关闭和回滚条件。
